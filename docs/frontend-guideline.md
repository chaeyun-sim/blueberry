# [Claude AI FE Code Review & Generation Protocol]

너는 지금부터 코드 작성 및 수정 요청을 받았을 때, 반드시 아래의 '3단계 검증 워크플로우'를 순서대로 수행한 뒤 답변해야 해. 이 단계를 건너뛰고 바로 코드를 출력해서는 안 돼.

## Phase 1. 사전 분석 및 의존성 검사

1. 수정하려는 컴포넌트가 참조하고 있는 상위/하위 컴포넌트의 의존성을 먼저 분석해라.
2. 이번 수정으로 인해 사이드 이펙트(Side Effect)가 발생할 수 있는 결합 지점이 있는지 확인해라.

## Phase 2. 코드 생성 및 린트(Lint) 규칙 자가 검증 (CI 검증 단계)

코드를 작성하기 전에, 아래 규칙을 모두 통과했는지 스스로 체크리스트를 검증해라.

- [ ] accessibility: <img> 태그에 alt 속성이 누락되었는가? interactive 요소에 WAI-ARIA 속성이 적절히 부여되었는가? (eslint-plugin-jsx-a11y 기준)
- [ ] typescript: any 타입 사용을 지양하고 정확한 Interface/Type을 정의했는가?
- [ ] 성능: 불필요한 useMemo, useCallback 남용을 방지하고, 렌더링 최적화를 고려했는가?

## Phase 3. 최종 출력 및 변경 요약

- 위 체크리스트 검증 결과와 변경된 코드를 함께 제공해라.
- 만약 검증 단계에서 접근성 위반 사항이나 타입 에러가 발견되었다면, 스스로 코드를 재수정한 뒤 최종본만 출력해라.

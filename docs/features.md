# 기능 명세서

---

## 1. 의뢰 관리

새로운 편곡 의뢰를 등록하고 상태별로 추적하는 핵심 기능.

### 1.1 의뢰 등록 (`/new`)

| 항목 | 내용 |
|------|------|
| 의뢰 입력 폼 | 곡명(title), 작곡가(composer), 편성(arrangement), 버전(version: easy/hard/pro), 마감일(deadline), 메모(notes) |
| AI 자동 파싱 | 카카오톡 스크린샷 업로드 → AI가 곡명·편성·마감 추출 → 폼 자동완성 |
| 곡 연결 | 기존 등록된 Song과 `song_id`로 연결 가능 (선택 사항) |
| 마감일 기본값 | 오늘로부터 14일 후 자동 설정 |
| 유효성 검증 | Zod 스키마 기반 클라이언트 검증 |

### 1.2 의뢰 목록 (`/commissions`)

| 항목 | 내용 |
|------|------|
| 상태 필터 | 대기 / 작업중 / 완료 / 취소 탭 필터링 |
| 의뢰 카드 | 곡명, 편성, 마감일, 상태 배지 표시 |
| 정렬 | 마감일 기준 정렬 |

### 1.3 의뢰 상세 (`/commissions/:id`)

| 항목 | 내용 |
|------|------|
| 의뢰 정보 | 곡명·작곡가·편성·버전·마감일·메모 조회 |
| 상태 변경 | 대기 → 작업중 → 완료 / 취소 드롭다운 |
| 납품 플래그 | `is_delivered` 토글 (납품 여부) |
| 연결된 편성 | 연결된 `Arrangement` 있으면 악보 상세로 링크 |

### 1.4 의뢰 수정 (`/commissions/:id/edit`)

등록된 의뢰의 모든 필드를 수정. AI 파싱 재실행 가능.

## 2. 악보 카탈로그

곡과 편성을 체계적으로 관리하는 카탈로그 기능. 의뢰와 독립적으로 운용 가능.

### 2.1 악보 등록 (`/scores/new`)

| 항목 | 내용 |
|------|------|
| 곡 정보 | 곡명(title), 영문 제목(english_title), 작곡가, 카테고리(CLASSIC/POP/K-POP/OST/ANI/ETC) |
| 편성 추가 | 악기 편성(arrangement) 문자열 + 버전(version) |
| ZIP 업로드 | 편성별 악보 파일을 ZIP으로 일괄 업로드 → 자동 매핑 |

### 2.2 편성 상세 (`/scores/:scoreId/arrangements/:arrangementId`)

| 항목 | 내용 |
|------|------|
| 편성 정보 | 악기 구성, 버전, 연결된 의뢰 |
| 파일 목록 | 첨부된 악보·음원 파일 목록 (label, file_type) |
| 파일 업로드 | 개별 파일 추가 업로드 |
| 파일 삭제 | 개별 파일 삭제 |
| 편성 삭제 | 소프트 삭제 (`deleted_at`) |

---

## 3. 파일 관리 (`/files`)

편성 파일을 중앙에서 관리하는 페이지.

| 항목 | 내용 |
|------|------|
| ZIP 업로드 카드 | ZIP 파일 드래그 앤 드롭 업로드 → 내부 파일을 편성에 자동 매핑 |
| 파일 타입 요약 | 파일 유형별(PDF, MP3, WAV 등) 집계 |
| 파일 목록 | 편성별 파일 목록 조회 및 다운로드 |

---

## 4. 대시보드 (`/`)

모든 의뢰와 매출 현황을 한눈에 파악하는 홈 화면.

| 위젯 | 내용 |
|------|------|
| 인사말 헤더 | 현재 시각 기반 Good Morning/Afternoon/Evening + 오늘 날짜 |
| 진행 중인 의뢰 | `ActiveCommissionsWidget` — 작업중 의뢰 목록 |
| 마감 임박 | `DeadlineWidget` — D-day 기준 정렬된 마감 목록 |
| 상태 도넛 차트 | `StatusDonutWidget` — 상태별 의뢰 분포 |
| 월별 매출 차트 | `MonthlyChart` — 월별 매출 추이 (recharts) |
| 매출 슬라이더 카드 | `RevenueSliderCard` — 이번 달 매출·전월 대비 |
| Discover 위젯 | `DiscoverWidget` — 악보 카탈로그 탐색 |
| 빠른 의뢰 등록 | `+` 버튼 → `/new`로 이동 |

---

## 5. 캘린더 (`/calendar`)

의뢰 마감일을 달력 형태로 시각화.

| 항목 | 내용 |
|------|------|
| 뷰 | 월별/주별/일별 전환 |
| 이벤트 | 의뢰 마감일을 이벤트로 표시, 상태별 색상 코딩 |
| 클릭 | 이벤트 클릭 → 해당 의뢰 상세 페이지로 이동 |
| 구현 | `react-day-picker` 기반 |

---

## 6. 매출 통계 (`/stats`)

Excel 판매 보고서를 업로드하여 통계를 자동 생성.

| 항목 | 내용 |
|------|------|
| Excel 업로드 | 월별 판매 보고서 Excel 파일 업로드 |
| 업로드 이력 | 업로드된 보고서 목록 (월, 파일명, 행 수) |
| 월별 매출 차트 | 월별 매출액·판매 수량 추이 |
| 카테고리별 분포 | CLASSIC/POP/K-POP/OST/ANI/ETC 분포 |
| 상위 곡 | 매출 기준 Top N 곡 및 편성 순위 |
| 계절 패턴 | 월별 평균 매출 패턴 분석 |
| 매출 집중도 | 파레토 차트 (상위 곡이 매출에서 차지하는 비중) |
| 트렌딩 곡 | 전월 대비 성장률 기준 트렌딩 곡 |

### Excel 업로드 상세 (`/files/excel/:uploadId`)

업로드된 보고서의 곡별 판매 내역 테이블 조회.

## 7. 음악 추천 (MusicRecommend)

Soundpost 연동을 통해 편곡 현황 조회.

| 항목 | 내용 |
|------|------|
| 상태 | `loading` / `arranged` / `not-arranged` / `error` |
| 목적 | 편곡 완료 여부 외부 시스템과 연동 확인 |
